app - страница где будут ссылки на все остальные страницы
editingPage - страница где будет выбор что конкретно изменить.Например Тест, Вопросы или же удалить Тест 
editTestPage - страница где будет можно обновить актуальные Вопросы в тесте
EditTestQuestion - страница где будет можно обновить актуальные даттые Теста
errorMessage - сообщение об ошибке
filter - возвращает массив категорий + фильтрует по ним данные
header - возвращает хедер, реагирующий на состояния модалки чтобы изменять поведение бургера
footer - возвращает кусок вертски чтобы не повторяться
mainPage - главная страница с тестами
modal - окошко, показывающее данные теста и дающий выбор Пройти тест или Отредактировать
createTest - страница где будет возможно создавать Новый Тест
createQuestions  - страница где будет возможно создавать Вопросы для Нового Теста
Questions - кусок который будет выводить вопросы в запущенном тесте
resultModal - после сдачи теста покажет количество баллов + пройденное время.+ кнопка домой
QuizItem - выводит информацию об одном конкретном тесте
Spinner - гифка загрузки для загрузки
Timer - секундомер считающий как долго юзер проходил тест
QuizContext - общие данные необходимые для пробрасывания
http.hooks - хук для отправки запросов на сервер
useQuizSlizder - слайдер для листания вопросов в активном тесте
QuizeService - набор методов для взаимодействия с сервером
