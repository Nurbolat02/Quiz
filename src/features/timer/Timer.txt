useImperativeHandle используется чтобы ребенок мог передать какой-то свой метод вверх родителю И родитель бы имел возможность этим методом пользоваться

forwardRef используется для того, чтобы useImperativeHandle было возможно отправить наверх.Он будет оборачивать наш компонент

Создаем стейт для секунд

Создаем Юс эффект

Проверяем флаг, который мы получяем из пропса если секундомер прямо сейчас идет, то ничего не делает (возвращаем пустой реторн)
Если секундомер не идет, то мы его создаем, обращаясь к состоянию которое изменяет стейт с секундами, чтобы оно увеличивало прошлое значение на 1 каждую секундну

В реторн мы напишем функционал для удаления созданного таймер 

Юз эффект следит ща флагом активности таймера

наружу мы будем пробрасывать метод, который будет выводить количество секунд

ну и еще создадим функцию которая принимает общее количество секунд и форматирует данные так, чтобы время выгляжело аккуратно (минуты + секунды)

в реторн возвращаем простенький JSX который принимает функцию по форматированию времени вместе с секундами


Чтобы было возможно теперь использовать прописанный тут метод в родителе, мы должны как бы связать их 
  const timerRef = useRef();
  и когда нам будут нужны секунды в родителе, мы просто обратимся 
  const totalSeconds = timerRef.current.getSeconds();
  И конечно нужно указать откуда изначално сам реф берется
    <Timer ref={timerRef} isRunning={isRunning && hasQuestions} />
