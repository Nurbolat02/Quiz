Состояния ошибки

Создаем useEffect без зависимостей чтобы он просто инициализировал верстку с категориями
В нем вызываем функцию getDataFromServer
getDataFromServer внутри себя меня состояние загрузки в тру, отправляет запрос для получения категорий, обрабатывает ответ, записывает его в набор категорий

Создаем переменную с категорией ОЛЛ в которую помещаем масив полученных даных, которых мы фильтруем и оставляем трлько тот, у которого категория равна ОЛЛ.И только этому единственному мы обращаемся по его АЙДИ чтобы достать номер и это номер записываем в activeCategoryId через setActiveCategoryId

Далее меням состояние загрузки на фол ( загрузка окончена) + отлавливаем ошибку 

Прописываем функцию для рендера полученных данных и вывод их на страницу
renderDataToLayout принимает данные, внутри себя создает список, в котором инициализирует на данных метод МЭП доставая через деструктуризацию АЙДИ + Имя категории и на каждый такой элемент создает ЛИ в котором
ключ = АЙДИ
категория = имени
в название класса динамически посдтавляется класс активности ЕСЛИ актуально активная категория (ее айди) совпадает с моментально создаваемым АЙДИ элемента 
добавляем функцию handleClick принимающую АЙДИ + ИМЯ и обновляющую активную категорию (из-за клика по ней) + отправляющую наверх ( в мэин ) имя категории на которую мы кликнули
Ну и выводим само название категории
создаем переменные Блок загрузки и Блок ошибки
В блоке загрузки пишем условие что если загрузка тру, мы выводим спинер.Если загрузка фолс, то выводим ничего
В блоке ошибки условие подобное.Если ошибка тру, то выводим ошибку иначе ничего
