Этот компонент отвечает за редактирование теста.
Достаем айди из ссылки
Достаем метод navigate из useNavigate
Создаем обьект (через стейт) с данными из формы, которые по дефолту пустые 
Имя, категория, время, описание, рейтинг, картинка
Создаем стейт для будущей загрузки в него массива с категориями
Создаем стейт для будущей загрузки в него масива с путями к картинкам
Достаем из QuizService необходимые нам методы для

Получения информации о тесте который мы редактируем
Для загрузки обновленных данных на сервер
Для получения иформации о категориях
Для получения информации о путях к картинкам

Создаем Юз еффект и в нем вызываем функцию для сбора данных
которая отправляе запрос для получения инфы о ТЕСТЕ + КАТЕГОРИИ + ПУТИ и сразу все это записываем в стейты

Далее создаем функцию для записи изменений в инпутах.Функция принимет ивент.
Из ивента мы можем достать сразу 2 значения деструктуризацией. Имя + значение.
Передаем в setFormData развернутый массив данных ( прошлый ) + добавляем ключ ИМЯ со значением ЗНАЧЕНИЕ 

Далее создаем функцию для сохранения изменений.Она принимает в себя событие, отменяет дефолтное поведение 
и вызываем метод для отправки данных, передавай во внутрь АЙДИ и самое ТЕЛО данных.
После чего отправляем юзера домой

В самом реторне ничего удивительного.Контролируемые инпуты, динамически создаваемые селекты и кнопка.
