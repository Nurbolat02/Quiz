Импортируем функцию для удаления теста из QuizService
Достаем АЙДИ полученный из URL

Возвращаем простую вертску в которой будет 3 ссылки.
ССылка для изменения теста будет вести на страницу с изменением теста
Ссылка для изменения вопросов будет вести на страницу для изменения вопросов
ССылка для удаления которая будет вести домой + она вызывает удаление теста по АЙДИ
