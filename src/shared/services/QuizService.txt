Это вспомогательный файл в котором будут прописываться все необходимые методы для работы с сервером.

Изначально достанем метод для неспоредственной самого обращения к серверу, а потом опишем методы для

Получения информации и всех тестах + обработка ответа в удобный обьект
Получения информации о всех категориях 
Получения информации о одной конкретной категории
Получение информации об одном конкретном тесте через его АЙДИ
Получение путей к картинкам

Метод по добавлению нового теста
Метод по обновлению существующего теста
Метод для удаления существующего теста
функция для обработки ответа с сервера

и все :)
